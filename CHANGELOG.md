# Changelog

## 1.7.0

- Package Animated Backgrounds and Liquid Glass 0.6.0 as one HACS dashboard module.
- Configure weather entities, helper entities, video paths, playback defaults and
  low-power settings through the external config.json without editing JavaScript.
- Keep personal configuration and videos outside the HACS-managed directory.
- Validate the generated bundle and publish GitHub releases from version tags.
